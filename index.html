فاطمه محبی | توسعه‌دهنده فول‌استک (Python / Next.js)

توسعه‌دهنده نرم‌افزار با تمرکز بر طراحی و پیاده‌سازی وب‌اپلیکیشن‌های مدرن، توسعه بک‌اند با Python و Django و ساخت رابط‌های کاربری پویا با React و Next.js.

دارای تجربه عملی در توسعه وب‌سایت‌های شرکتی و فروشگاهی، طراحی API، کار با پایگاه‌های داده و پیاده‌سازی نرم‌افزارهای دسکتاپ؛ با تأکید بر معماری اصولی، کدنویسی تمیز و راهکارهای متناسب با نیاز کسب‌وکارها.

دانلود رزومه
درباره من

Full-Stack Developer | Python, Django & Next.js

من فاطمه محبی، توسعه‌دهنده فول‌استک با تمرکز بر Python و فناوری‌های مدرن توسعه وب هستم. در زمینه تحلیل نیازمندی‌ها، طراحی ساختار نرم‌افزار و توسعه وب‌اپلیکیشن‌های کاربردی فعالیت می‌کنم و به پیاده‌سازی راهکارهایی اهمیت می‌دهم که علاوه بر عملکرد مناسب، قابل نگهداری و توسعه باشند.


در بخش بک‌اند با Python، Django و Django REST Framework و در بخش فرانت‌اند با JavaScript، TypeScript، React و Next.js کار می‌کنم. همچنین تجربه کار با پایگاه‌های داده رابطه‌ای از جمله PostgreSQL، SQL Server و SQLite و ابزارهای مدیریت داده مانند SQLAlchemy و Prisma را دارم.


تجربه عملی من شامل توسعه وب‌سایت‌های شرکتی و فروشگاهی، طراحی APIهای RESTful، سیستم‌های مدیریت محتوا، کاتالوگ محصولات، سبد خرید و نرم‌افزارهای دسکتاپ است. در پروژه‌های مختلف با معماری سه‌لایه، ساختارهای ماژولار و معماری Monorepo کار کرده‌ام.


در فرآیند توسعه نرم‌افزار، به تفکیک مسئولیت‌ها، طراحی ساختار مناسب، خوانایی و نگهداری‌پذیری کد، تست و اشکال‌زدایی اهمیت می‌دهم. همچنین از Git و GitHub برای کنترل نسخه و مدیریت تغییرات پروژه استفاده می‌کنم. هدفم ارائه راهکارهای نرم‌افزاری قابل اعتماد، توسعه‌پذیر و متناسب با نیاز واقعی کسب‌وکارهاست.

مهارت‌های تخصصی

  • زبان‌های برنامه‌نویسی: Python، JavaScript، TypeScript، SQL
  • توسعه Back-End: Django، Django REST Framework
  • توسعه Front-End: React، Next.js، HTML5، CSS3
  • طراحی رابط کاربری: Tailwind CSS، Bootstrap
  • پایگاه داده: PostgreSQL، SQL Server، SQLite
  • ابزارهای مدیریت داده: SQLAlchemy، Prisma
  • معماری نرم‌افزار: معماری سه‌لایه، ساختار ماژولار و Monorepo
  • کیفیت کد: Clean Code، تست، Debugging و TypeScript Strict Mode
  • ابزارهای توسعه: Git، GitHub، Node.js، ESLint و Prettier
